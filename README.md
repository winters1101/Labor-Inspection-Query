# 勞動檢查違規查詢

一頁式查詢網站：選擇**直轄市／縣市政府**與**民國年月查詢區間**，即可看到該地區、該期間內違反《勞動基準法》遭裁罰的事業單位，並整理：

- **產業別統計**：哪些產業最常被罰（件數、罰鍰合計、占比）
- **違反條文排行**：最常違反哪一條（如第 24 條加班費、第 32 條超時、第 38 條特休）
- **重複違規事業單位**：期間內被罰 2 次以上的公司、財團法人或商號
- **裁罰明細**：處分日期、事業單位、違反條文與內容、罰鍰金額，可下載 CSV

目的是讓初次就業、二度就業的勞工在求職前查一下，避開常違法的雇主。頁面採和風簡素設計，支援手機與深色模式。

## 官方資料從哪裡來？

各直轄市、縣市政府勞動局處依《勞動基準法》第 80 條之 1，須公布違法雇主的名稱、負責人、處分期日、違反條文及罰鍰金額。
這些名單由勞動部統一彙整在：

| 來源 | 說明 |
|---|---|
| [違反勞動法令事業單位（雇主）查詢系統](https://announcement.mol.gov.tw/) | 勞動部官方查詢系統（106 年 12 月上線），可依縣市、名稱、法規、處分日期查詢 |
| [勞動部開放資料：違反勞動基準法](https://apiservice.mol.gov.tw/OdService/rest/dataset/109896)（`A17000000J-030225-svj`） | 上述系統的開放資料 CSV，**本站的資料來源** |
| [勞動部 違反勞動法令公布專區](https://www.mol.gov.tw/1607/28162/28166/28246/nodelist) | 各縣市公布頁面入口 |
| 各縣市勞動局處網站（如[桃園市政府勞動局公布專區](https://lhrb.tycg.gov.tw/News_Content.aspx?n=4882&s=653964)） | 地方政府自行公布的名單，內容同樣匯入勞動部系統 |

CSV 欄位：`主管機關、公告日期、處分日期、處分字號、事業單位名稱或負責人、違法法規法條、違反法規內容、罰鍰金額、備註說明`。

> ⚠️ 官方資料**沒有「產業別」欄位**。本站以事業單位名稱中的關鍵字（如「營造」「醫院」「保全」「餐飲」）推估產業，
> 規則見 [`scripts/industry.py`](scripts/industry.py)，約三成名稱無法判別會歸入「其他／無法判別」。頁面上皆標示「推估」。

## 架構

```
index.html              單頁查詢介面
assets/style.css        和風樣式（生成り底色、墨色文字、藍／朱點綴）
assets/app.js           查詢、統計、分頁、CSV 匯出（純 JavaScript，無框架）
assets/laws.js          勞基法常見條文的簡要說明
data/index.json         代碼表（主管機關、產業別）與各年度筆數
data/records/YYYY.json  依處分日期西元年分檔的裁罰紀錄（字典壓縮）
scripts/build_data.py   下載官方 CSV → 清理、去重、推估產業 → 輸出 data/
scripts/industry.py     產業別／組織型態推估規則
tests/                  資料處理的單元測試
.github/workflows/      每日自動更新資料並部署 GitHub Pages
```

網站是純靜態檔案，瀏覽器只讀取 `data/` 內的 JSON，不直接連線勞動部（避免跨網域與官方網站負載問題）。
查詢時只載入所選期間涵蓋的年度檔（每年約 1 MB）。

## 使用方式

### 本機預覽

```bash
python3 -m http.server 8000
# 開啟 http://localhost:8000
```

（需透過網頁伺服器開啟，直接雙擊 `index.html` 會因瀏覽器安全限制無法讀取資料。）

### 更新資料

```bash
python3 scripts/build_data.py              # 下載勞動部最新 CSV，併入既有資料
python3 scripts/build_data.py --csv 下載的檔案.csv
```

新資料會與 `data/` 既有紀錄合併並去重，因此官方檔案即使只保留近幾年，舊紀錄也不會消失。

### 自動更新與部署（GitHub Pages）

1. 將程式合併到 `main` 分支。
2. 到 GitHub 儲存庫 **Settings → Pages**，Source 選 **GitHub Actions**。
3. 工作流程 `.github/workflows/update-and-deploy.yml` 會在每日台灣時間 04:17 下載最新資料、提交變更並重新部署；
   也可在 Actions 頁面手動執行。若勞動部網站暫時連不上，會沿用現有資料照常部署。

## 目前收錄

初始資料為民國 109 年 1 月至 115 年 9 月（處分日期）共 56,736 筆勞基法裁罰紀錄，
取自勞動部開放資料（經由 [kiang/announcement.mol.gov.tw](https://github.com/kiang/announcement.mol.gov.tw) 的每日存檔匯入，
該存檔直接鏡像同一份官方資料集）。之後由上述工作流程直接自勞動部更新。

## 注意事項

- 查詢期間以**處分日期**為準；公告通常晚於處分，最近一兩個月的資料可能尚未完整。
- 一件處分可能同時違反多條條文，「違反條文排行」中每條各計一次，罰鍰以整件處分計。
- 部分處分仍在行政救濟中或事後撤銷（見備註），實際情形請以主管機關公告為準。
- 本站為民間整理的非官方工具，與勞動部及各地方政府無隸屬關係。資料依[政府資料開放授權條款](https://data.gov.tw/license)使用。
